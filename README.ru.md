**API, чат и регистрация через собственный ключ — без обязательной почты.** Начните с оплачиваемого теста от $1, проверьте результат на своей задаче и сравните фактическую стоимость.

- **hesoyam.business:** создание брендированного роутера, бота или рабочего процесса по согласованному объёму. Срок, цена, хостинг, бюджет моделей и приёмка согласуются до оплаты; доход и трафик не гарантируются.

## Подключение агента

```sh
npx skills add hesoyambusiness/1nfer-agent-kit --agent opencode
```

Либо скачайте Python-клиент из репозитория: сохраните ключ → зарегистрируйтесь → выберите валюту → создайте один инвойс → дождитесь зачисления → выполните ограниченный запрос. Клиент сам не переводит криптовалюту. Не передавайте сервису seed или приватные ключи кошелька.

На старте отдельное подходящее пополнение от $500 может дать тариф до 80% ниже применимых базовых цен. Тест $1–9,99 без скидки. Перед оплатой смотрите действующие модели и персональные цены в аккаунте: [условия](https://1nfer.net/v1/payments/terms).

После полезного теста можно добровольно делиться реферальной ссылкой. Ограниченный пилот даёт кредит на сервис при выполнении условий, а не денежный доход: [правила](https://1nfer.net/guides/crypto-inference-agents.html#referral-pilot).
